# 🛒 Retail Sales Analysis and Prediction

An end-to-end Data Science project that performs Exploratory Data Analysis (EDA) and predicts retail sales using Machine Learning techniques.

---

## 📌 Project Overview

This project analyzes a retail sales dataset to identify sales trends, customer behavior, and regional performance. It also builds machine learning models to predict future sales based on various business features.

The project demonstrates a complete Data Science workflow, including:

- Data Collection
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Engineering
- Machine Learning
- Model Evaluation

## 📊 Dataset

The dataset contains retail transaction records with the following features:

| Feature | Description |
|----------|-------------|
| Order_Date | Date of purchase |
| Category | Product category |
| Region | Sales region |
| Segment | Customer segment |
| Quantity | Number of products sold |
| Discount | Discount offered |
| Sales | Total sales amount |
| Profit | Profit earned |

## 🤖 Machine Learning Models

The following regression algorithms were implemented:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

Each model is evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

The best-performing model is selected for final sales prediction.

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/yourusername/Retail-Sales-Analysis.git
```

Move into the project directory:

```bash
cd Retail-Sales-Analysis
```

Install dependencies:

```bash
pip install pandas numpy matplotlib scikit-learn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open:

```
Retail_Sales_Analysis_Complete.ipynb
```

Run all cells to reproduce the analysis and prediction results.
